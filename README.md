# Progressus in Lingua Anglica

学習用 CD-ROM（CD-ROM XA）教材リピーターの**互換プレーヤー**（Windows / WinForms / .NET 9）。
実機の操作パネルをエミュレートし、ディスク上の音声（XA ADPCM）を抽出・デコードして再生します。

> 本プログラムは互換実装です。特定メーカー・製品の商標表記（ロゴ・型番等）は含みません。

開発中（work in progress）です。

---

## これは何か

ある英語教材には、専用の「CD リピーター」と呼ばれる再生機が付属していました。教科書の各課（チャプター）を番号で頭出しし、英文を 1 文ずつ聞いて繰り返したり、設問に数字ボタンで答えるクイズ学習ができる装置です。音声は CD-ROM XA 形式でディスクに収録され、再生位置や連続再生・クイズの制御情報は専用のテーブルファイル（`C*.TBL`）に格納されています。

本プロジェクトは、その実機の操作パネルと再生挙動を Windows 上で再現し、オリジナルのディスク（またはそのコピー）から音声を抽出して再生する互換プレーヤーです。

### 用語

| 用語 | 意味 |
|------|------|
| チャプター | 教材の課に相当。`Cnnn.TBL` 1 ファイル＝ 1 チャプター（`nnn` は番号） |
| インデックス | チャプター内の再生区間グループ（INDX チャンク） |
| サブインデックス | インデックスをさらに細分した区間（SUB0 チャンク）。クイズの出題・選択肢などに使われる |
| セグメント | 本実装での再生単位。インデックス、またはサブインデックス 1 件に対応し、チャプターリストの 1 行になる |
| 制御子 (control word) | 各区間の連続再生フラグ・種別（通常/クイズ）を表す 4 バイト値 |
| チャンネル | 1 枚のディスクに最大 16 系統の音声を多重化する単位（0–15） |

## 特徴（現状の実装）

- **オンデマンド読み込み** — `SOUND.RTF`（全音声を 1 つにまとめた数百 MB のファイル）を起動時に全走査しません。各セクタの時刻（MSF）がファイル内で単調増加する性質を利用し、再生したい区間の先頭を**二分探索**で特定して、その区間だけをシーケンシャルに読み出します。光学ドライブやネットワーク等の低速メディアでも待ち時間が少なく、HDD/SSD へコピーする必要はありません。
- **CD 自動認識** — 対応ディスクの挿入/取り出しを検知して自動でロード/解放します。起動時に挿入済みのディスクも認識します。
- **チャプターの逐次表示** — `C*.TBL` の解析はバックグラウンドで行い、解析できたチャプターから順次リストへ反映するため、ファイルを開いた直後から操作できます（解析所要時間はステータスバーに表示）。
- **実機風 UI** — コード描画の 7 セグメント表示窓（CHAPTER / STEP / INDEX / ANSWER と再生 ▶ / 一時停止 ‖ マーク）＋操作パネルをコードで構築。
- **NAudio による再生** — 一時停止 / 再開、末尾到達の検知、0.5 秒ギャップ付きループ、音量調整に対応。
- **連続再生** — 制御子に従って、区間の末尾で次のサブインデックス／インデックスへ自動的に続けて再生し、ストップ指定の区間で止まります。
- **録音 / 再生（REC / PB）** — マイクから最大 16 秒録音し、再生できます（実機の REC / PB 相当）。
- **WAV 保存** — チャプターリストの行を右クリックして、その区間を WAV ファイルへ書き出せます。

## 使い方

### ディスク / フォルダを開く

- **OPEN** ボタンで、ディスクがマウントされたドライブ、またはディスクデータのルートフォルダーを選択します。
- 対応ディスクを挿入すると**自動認識**して読み込みます。
- ルート直下に `SOUND.RTF` と `C*.TBL` がある構成を読み込みます。
- 読み込み後、チャプターはバックグラウンドで順次リストに追加されます。

### 操作パネル

| ボタン | 動作 |
|--------|------|
| OPEN | ディスク / フォルダを開く |
| SELECT | チャプター → ステップ → インデックス の選択モードを順に切り替え |
| CLEAR | 選択中フィールドの数値を 0 に戻す |
| 数字 1〜0 | SELECT 中は番号入力／アンサー（クイズ）中は選択肢の選択。それ以外は無効 |
| ◀◀（STEP 戻る） | 再生中チャプターの先頭へ。0.5 秒の一時停止中に再度押すと前チャプター先頭へ |
| ▶▶（STEP 進む） | 次チャプターの先頭へ |
| ▶‖（PAUSE） | 再生中は一時停止 / 一時停止中は再開。SELECT 中は選択インデックスを先頭から再生 |
| ◀（BACK） | 再生中インデックスの先頭へ。0.5 秒の一時停止中に再度押すと前インデックス先頭へ（サブインデックス再生中でも必ず親インデックス先頭へ） |
| ■（STOP） | 停止（インデックスの選択状態は保持。GO / PAUSE で選択中インデックスから再開） |
| GO | 再生中 / 一時停止 / 末尾停止中は次インデックスの先頭へ。SELECT 中は選択を確定して再生 |
| REPEAT | 現在のセグメントを 0.5 秒ギャップで繰り返し再生。押すごとに 一時停止 ⇄ 先頭からループ |
| REC | **押している間**だけマイク録音（最大 16 秒） |
| PB | 直前の録音を再生 |
| VOLUME | 音量 |

※ MIC はインジケータ表示で、ボタンではありません。POWER は実機ではインジケータのため設けていません。

### チャプター／インデックスを選んで再生する（SELECT）

1. **SELECT** を押すとチャプター選択状態に入る（押すたびに チャプター→ステップ→インデックス と切り替わる）。
2. 数字ボタンで番号を入力する。フィールドに入った直後の最初の 1 桁は置き換え、以降は追記（既存番号からの続き入力にはならない）。**CLEAR** で 0 に戻せる。
3. **GO** または **▶‖** で確定し、選択したチャプター・インデックスを先頭から再生する。
   - ステップ番号は何を入力しても強制的に 1 になります（教材仕様）。
   - 存在しないチャプター／インデックスを指定した場合は初期状態へ戻ります。

### クイズ（アンサー）

- クイズのインデックスでは、サブインデックス **0 が出題**、**1 以降が選択肢**です。
- 出題が再生されると ANSWER 桁に `A` が点灯。停止・一時停止中、および誤答の再生中は `A` が点滅します。
- 解答は数字ボタンで行い、**有効なのは選択肢の数だけ**（範囲外の数字は無効化されます）。選んだ番号は ANSWER 隣の桁に表示され、対応する選択肢の音声が再生されます。

### 表示窓（7 セグメント）

左端に ▶（再生中）/ ‖（一時停止・末尾停止）マーク、上辺に CHAPTER / STEP / ANSWER ラベル。桁の並びは次のとおりです。

```
▶                  CHAPTER     STEP        ANSWER
‖   [チャプター3桁]  [STEP=1] - [INDEX2桁]   [A][選択番号]
```

| 状態 | 表示 |
|------|------|
| 未読込 | ` OPEN` |
| 読み込み中 | 空表示＋再生マーク点滅 |
| 再生中 | 各桁を表示＋再生マーク点灯 |
| 一時停止／末尾停止／プリロール中 | 各桁を表示＋一時停止マーク点灯 |

- チャプターは 3 桁（ゼロ埋めせず空白詰め）、ステップは常に 1、インデックスは 2 桁ゼロ埋め。
- ANSWER 桁はクイズ時のみ `A`（点灯/点滅）を表示します。

### チャプターリスト

- 「チャプター一覧」ボタンでウィンドウを下方向に**展開 / 折りたたみ**します。
- 再生中の行を**追尾**して選択・スクロールします。
- 行を**ダブルクリック**で直接再生、**右クリック**で WAV 保存ダイアログを開きます。
- 各行は `[チャプター]-(インデックス)` または `[チャプター]-(インデックス-サブ)` と時刻範囲、種別アイコン（❓出題 / ⭕正答 / ❌誤答 / 🔽次サブへ / ⏬次インデックスへ）を表示します。

## 動作の仕組み

### オンデマンド抽出

`SOUND.RTF` のセクタは、ディスク上の収録順＝時刻（MSF）の昇順でファイルに並んでいます。`XaSectorLocator` はこの単調性を使って次のように動きます。

1. 再生したい区間の開始フレーム以上になる最初のセクタを、ヘッダ（先頭 18 バイト）だけを読む**二分探索**で特定する。
2. そこから前方へ、64 セクタ単位でまとめて読み込みながら、対象チャンネルかつ区間内のセクタのユーザーデータ（各 2336 バイト）を連結する。
3. 終了フレームを越えたら打ち切る。

これにより、ファイル全体の走査を避け、必要な区間ぶんだけを読みます。直近に抽出した区間は小さな LRU キャッシュに保持し、連続再生や保存の再抽出を抑えます。`XaRiffReader` はセッション中ファイルハンドルを開いたまま保持し、セクタごとの開き直しを避けます。

### 連続再生・リピート・プリロール

- 再生が末尾に達すると、その区間の制御子を見て次の動作を決めます。`次サブインデックスへ` ならサブインデックスを、`次インデックスへ` なら次インデックスを続けて再生し、`ストップ` なら末尾停止します。
- STEP / BACK / GO による区間移動は、**0.5 秒の一時停止（プリロール）を挟んでから**再生を開始します。STEP 戻る・BACK はこの一時停止中の再押下で「さらに前」へ移動します。
- REPEAT は現在のセグメントを 0.5 秒ギャップで繰り返します。別の区間へ移る操作を行うとリピートは解除されます。

### 状態（デバイスモード）

`NoDisc`（未読込）/ `Loading`（読み込み中）/ `Idle`（停止・待機）/ `PreRoll`（再生直前の 0.5 秒一時停止）/ `Playing`（再生中）/ `Paused`（一時停止）/ `Tail`（末尾まで再生して停止）。表示窓・マーク・数字ボタンの有効状態はこのモードと SELECT/クイズ状態から決まります。

### CD 自動認識

`WM_DEVICECHANGE`（ボリュームの着脱）を監視します。

- **挿入**（`DBT_DEVICEARRIVAL`）：該当ドライブ直下に `SOUND.RTF` があれば自動ロード。マウント直後は読めないことがあるため、0.8 秒間隔で最大 6 回リトライします。
- **取り出し**（`DBT_DEVICEREMOVECOMPLETE`）：読み込み中のドライブなら状態を破棄し、開いていたファイルハンドルを解放します。
- **起動時**：準備完了済みの CD-ROM ドライブを走査し、対応ディスクがあれば自動ロードします。

ボリュームのメディア変更通知は全トップレベルウィンドウへ自動でブロードキャストされるため、デバイス登録（`RegisterDeviceNotification`）は不要です。

## データ形式（実装準拠の技術仕様）

実装している範囲をまとめます。背景や全体像は末尾の参考記事も参照してください。

### セクタ（2352 バイト）

| オフセット | サイズ | 内容 |
|-----------|--------|------|
| 0x00–0x0B | 12 | 同期パターン |
| 0x0C–0x0E | 3 | ブロックアドレス（BCD の 分:秒:フレーム = MSF） |
| 0x0F | 1 | モード |
| 0x10–0x17 | 8 | サブヘッダ（ファイル番号 / チャンネル / サブモード / 符号化情報＋コピー） |
| 0x18–0x917 | 2304 | ユーザーデータ（XA ADPCM） |
| 0x918–0x92B | 20 | 末尾ブランク |
| 0x92C–0x92F | 4 | EDC（未使用） |

- セクタ先頭 16 バイト（同期 12 + ヘッダ 4）を飛ばした **2336 バイト**（サブヘッダ 8 + データ 2304 + ブランク 20 + EDC 4）を「ユーザーデータ」として抽出します。
- 時刻（MSF）はバイト 0x0C–0x0E、チャンネル番号はサブヘッダ内のオフセット 0x11（=セクタ先頭 +17）から読みます。

#### サブモード / 符号化情報（実装値）

- サブモード `0x64`：RealTime・Form2・Audio。本実装は **Form2 かつ Audio** のセクタのみデコードします。
- 符号化情報 `0x04`：4bit / 18,900Hz / モノラル。本実装は **4bit・モノラルのみ**対応です。

#### チャンネルの多重化

1 枚に最大 16 チャンネルが多重化され、セクタはチャンネルをまたいで交互に並びます（おおよそ 16 セクタごとに同一チャンネルが現れる）。抽出時は対象チャンネルのセクタだけを拾います。各チャプターの参照チャンネルは TRCK ヘッダで指定されます。

### SOUND.RTF（RIFF CDXA）

`RIFF` + サイズ(LE32) + `CDXA` → `fmt `（サイズ 16）→ `data` の順。`data` チャンク以降が 2352 バイト×セクタ数です。本実装はヘッダのみを読んで `data` の位置とサイズ、先頭セクタの基準時刻を取得し、本体はオンデマンドでシークします。

### C*.TBL（チャプターテーブル）

`Cnnn.TBL`（`nnn` = チャプター番号）を解析します。`CHAP.TBL` は別用途のため**現状未使用**で、チャプターは `C*.TBL` から導出します。

**TRCK ヘッダ**

| オフセット | サイズ | 内容 |
|-----------|--------|------|
| 0x00–0x03 | 4 | `"TRCK"` |
| 0x08–0x09 | 2 | BE16 トラック全体長 |
| 0x0A–0x0B | 2 | BE16 ファイル番号 |
| 0x0C | 1 | チャンネル番号（0–15） |
| 0x0D | 1 | インデックス数 |
| 0x0E–0x0F | 2 | BE16 ヘッダ長（通常 0x0010） |

**INDX チャンク**（通常 0x10〜）

```
"INDX" + 予約(4) + 長さ BE16 + インデックス数 N BE16
  → 制御子   4 バイト × N
  → 時刻ペア 8 バイト × N （開始MSF 4B + 終了MSF 4B、またはサブインデックスポインタ）
```

**SUB0 チャンク**

```
"SUB0" + 予約(4) + 長さ BE16 + サブ数 M BE16
  → 制御子   4 バイト × M
  → 時刻ペア 8 バイト × M
```

インデックスの制御子が `0x80000000` のとき、その時刻ペア位置に SUB0 へのオフセット（先頭からの相対）が入り、そのインデックスはサブインデックスを持ちます。

### 制御子（control word, 4 バイト）

8 桁 16 進表記の上位 2 ニブルで判定します。

| ニブル | 意味 | 値 |
|--------|------|----|
| 1 文字目 | 連続再生フラグ | `1`=次インデックスへ / `2`=次サブインデックスへ / その他=ストップ |
| 2 文字目 | 種別 | `9`=クイズ出題 / `5`=クイズ正答 / `3`=クイズ誤答 / その他=通常 |

特殊値 `0x80000000` … サブインデックスを持つ（時刻ペア位置が SUB0 オフセット）。

例: `0x01000000`=再生後に停止、`0x11000000`=次インデックスへ、`0x21000000`=次サブインデックスへ、`0x09000004`=クイズ出題、`0x05000000`=正答、`0x03000000`=誤答。

### 時刻コード（MSF / フレーム）

時刻ペアは `[00][分(BCD)][秒(BCD)][フレーム(BCD)]` の 4 バイトです（サブインデックスでは 4 バイト目にインデックス番号や `0x01` が入る特例があります）。本実装では

```
フレーム = (分 × 60 + 秒) × 75 + フレーム   （75fps の絶対フレーム）
```

として扱い、セクタの MSF と TBL の時刻を**直接比較**します（リードイン補正は行いません）。

### クイズ（アンサー）の対応付け

- サブインデックス **0 = 出題**、**1 以降 = 選択肢**。
- 数字ボタン K（1 始まり）は **サブインデックス番号 K** に対応します。
- 有効な選択肢は **選択肢数（= サブインデックス数 − 1）** の範囲のみ。
- 種別フラグ `9`=出題、`5`=正答、`3`=誤答 に応じて ANSWER 桁の点灯/点滅を切り替えます。

### XA ADPCM デコード

ユーザーデータ 2304 バイト = **18 サウンドグループ × 128 バイト**。

```
サウンドグループ(128B)
  0x00–0x0F  サウンドパラメータヘッダー（16B）… 各ブロックの Shift/Filter（冗長コピーあり）
  0x10–0x7F  ADPCM データワード（28 ワード × 4 バイト = 112B）
```

- モノラルでは 1 グループ = 8 ブロック × 28 サンプル = **224 サンプル**、1 セクタ = 224 × 18 = **4032 サンプル**。
- **ブロックヘッダ（1 バイト）**：bit5–4 = フィルタ（0–3）、bit3–0 = シフト。`shift = 12 − (header & 0x0F)`（範囲外は 9 にフォールバック）、`filter = (header & 0x30) >> 4`。
- データワードは 4 バイト LE。各ワードから 4bit ニブルを取り出し（ブロックの偶奇で下位/上位ニブルを選択）、28 サンプルを順に復元します。

**フィルタ係数**

```
PosTable = { 0, 60, 115,  98, 122 }   // f0
NegTable = { 0,  0, -52, -55, -60 }   // f1
```

**デコード式**（4bit 符号付きニブル `nib` を符号拡張後）

```
sample = (nib << shift) + ((old * f0 + older * f1 + 32) >> 6)
```

- `old`, `older` は前回・前々回の出力。予測フィルタの状態は**セクタをまたいで保持**します。
- 結果は −32768〜+32767 にクリップ。
- 出力は 18,900Hz / 16bit / モノラルの PCM。

## 制限・未実装

- `CHAP.TBL`、CD-DA トラック（警告音声）は未対応。
- ステレオおよび 8bit XA ADPCM は未対応（モノラル 4bit・18,900Hz 固定）。
- クイズの正誤判定演出は表示中心の部分実装。
- 録音（REC/PB）は実機の代替実装で、マイク入力に依存します。
- オンデマンド抽出はセクタ時刻が単調増加である前提です（通常の CD-XA リップでは成立）。
