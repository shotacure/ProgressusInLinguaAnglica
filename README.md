# Progressus in Lingua Anglica

学習用 CD-ROM（CD-ROM XA）教材リピーターの**互換プレーヤー**（Windows / WinForms / .NET 9）。
実機の操作パネルをエミュレートし、ディスク上の音声（XA ADPCM）を抽出・デコードして再生します。

> 本プログラムは互換実装です。特定メーカー・製品の商標表記（ロゴ・型番等）は含みません。

開発中（work in progress）です。

---

## 特徴（現状の実装）

- **オンデマンド読み込み** — `SOUND.RTF` を起動時に全走査せず、必要な区間だけを時刻(MSF)の単調性を使った二分探索でシークして抽出します。光学ドライブやネットワーク等の低速メディアでも待ち時間が少なく、HDD/SSD へコピーする必要はありません。
- **CD 自動認識** — 対応ディスクの挿入/取り出しを検知して自動でロード/解放します。起動時に挿入済みのディスクも認識します。
- **実機風 UI** — コード描画の 7 セグメント表示窓（CHAPTER / STEP / INDEX / ANSWER と再生 ▶ / 一時停止 ‖ マーク）＋操作パネルをコードで構築。
- **NAudio による再生** — 一時停止 / 再開、末尾到達の検知、0.5 秒ギャップ付きループに対応。
- **録音 / 再生（REC / PB）** — マイクから最大 16 秒録音し、再生できます（実機の REC / PB 相当）。
- **WAV 保存** — チャプターリストの行を右クリックして、その区間を WAV ファイルへ書き出せます。

## 使い方

### ディスク / フォルダを開く

- **OPEN** ボタンで、ディスクがマウントされたドライブ、またはディスクデータのルートフォルダーを選択します。
- 対応ディスクを挿入すると**自動認識**します。
- ルート直下に `SOUND.RTF` と `C*.TBL` がある構成を読み込みます。

### 操作パネル

| ボタン | 動作 |
|--------|------|
| OPEN | ディスク / フォルダを開く |
| SELECT | チャプター → ステップ → インデックス の選択モードを順に切り替え |
| CLEAR | 選択中フィールドの数値を 0 に戻す |
| 数字 1〜0 | SELECT 中は番号入力／アンサー（クイズ）中は選択肢の選択。それ以外は無効 |
| ◀◀（STEP 戻る） | 再生中チャプターの先頭へ。0.5 秒の一時停止中に再度押すと前チャプター先頭へ |
| ▶▶（STEP 進む） | 次チャプターの先頭へ |
| ▶‖（PAUSE） | 再生中は一時停止 / 一時停止中は再開。SELECT 中は選択インデックスを先頭から再生 |
| ◀（BACK） | 再生中インデックスの先頭へ。0.5 秒の一時停止中に再度押すと前インデックス先頭へ（必ず親インデックス先頭へ） |
| ■（STOP） | 停止（インデックスの選択状態は保持。GO / PAUSE で選択中インデックスから再開） |
| GO | 再生中 / 一時停止 / 末尾停止中は次インデックスの先頭へ。SELECT 中は選択を確定して再生 |
| REPEAT | 現在のセグメントを 0.5 秒ギャップで繰り返し再生。押すごとに 一時停止 ⇄ 先頭からループ |
| REC | **押している間**だけマイク録音（最大 16 秒） |
| PB | 直前の録音を再生 |
| VOLUME | 音量 |

※ MIC はインジケータ表示で、ボタンではありません。POWER は実機ではインジケータのため設けていません。

### 表示窓（7 セグメント）

- 左端に ▶（再生中）/ ‖（一時停止・末尾停止）マーク。
- 上辺ラベル：CHAPTER / STEP / ANSWER。
- 桁：`チャプター(3桁) ステップ(常に1) - インデックス(2桁・ゼロ埋め)  ANSWER(A / 選択番号)`。
- ファイル未読込時は ` OPEN`、読み込み中は再生マークが点滅。

### チャプターリスト

- 「チャプター一覧」ボタンでウィンドウを下方向に**展開 / 折りたたみ**。
- 再生中の行を**追尾**して選択・スクロール。
- 行を**ダブルクリック**で直接再生、**右クリック**で WAV 保存。

## アーキテクチャ

| 構成要素 | 役割 |
|----------|------|
| `Xa/XaRiffReader` | RIFF CDXA（`SOUND.RTF`）を開き、ファイルハンドルを保持。ヘッダ／セクタをオンデマンド読み出し |
| `Xa/XaSectorLocator` | 時刻(MSF)の単調増加性を使い、目的区間を二分探索→区間のみシーケンシャル読み。小さな LRU キャッシュ付き |
| `Xa/XaAdpcmDecoder` | XA ADPCM（4bit）→ PCM16 モノラルへデコード |
| `Model/TblParser`, `Model/TrackTable` | `C*.TBL` の TRCK / INDX / SUB0 を解析し、チャプター・インデックス・サブインデックス構造を構築 |
| `Audio/PlaybackEngine` | NAudio による再生（再生 / 一時停止 / 再開 / 停止 / 末尾検知 / 音量） |
| `Audio/MicRecorder` | NAudio による録音（REC）と再生（PB） |
| `Controls/SevenSegmentDisplay` | 7 セグメント表示窓のコード描画 |
| `MainForm`, `MainForm.Device` | UI 構築・読み込み・状態機械（SELECT / 連続再生 / リピート / プリロール / クイズ） |

## データ形式（実装準拠の技術仕様）

実装している範囲をまとめます。背景や全体像は末尾の参考記事も参照してください。

### セクタ（2352 バイト）

| オフセット | サイズ | 内容 |
|-----------|--------|------|
| 0x00–0x0B | 12 | 同期パターン |
| 0x0C–0x0E | 3 | ブロックアドレス（BCD の 分:秒:フレーム = MSF） |
| 0x0F | 1 | モード |
| 0x10–0x17 | 8 | サブヘッダ（ファイル番号 / チャンネル / サブモード / 符号化情報＋コピー） |
| 0x18–0x917 | 2304 | ユーザーデータ（XA ADPCM） |
| 0x918–0x92B | 20 | 末尾ブランク |
| 0x92C–0x92F | 4 | EDC（未使用） |

- セクタ先頭 16 バイト（同期 12 + ヘッダ 4）を飛ばした **2336 バイト**（サブヘッダ 8 + データ 2304 + ブランク 20 + EDC 4）を「ユーザーデータ」として抽出します。
- サブヘッダのチャンネル番号は先頭から **オフセット 0x11（=セクタ先頭 +17）**。

#### サブモード / 符号化情報（実装値）

- サブモード `0x64`：Form2・Audio・RealTime（本実装は Form2 かつ Audio のセクタのみデコード）。
- 符号化情報 `0x04`：4bit / 18,900Hz / モノラル（本実装は 4bit・モノラルのみ対応）。

### SOUND.RTF（RIFF CDXA）

`RIFF` + サイズ + `CDXA` → `fmt `（サイズ 16）→ `data` の順。`data` チャンク以降が 2352 バイト×セクタ数。本実装はヘッダのみ読んで `data` の位置とサイズを取得し、本体はオンデマンドでシークします。

### C*.TBL（チャプターテーブル）

`Cnnn.TBL`（`nnn` = チャプター番号）を解析します（`CHAP.TBL` は別用途のため**現状未使用**で、チャプターは `C*.TBL` から導出）。

**TRCK ヘッダ**

| オフセット | サイズ | 内容 |
|-----------|--------|------|
| 0x00–0x03 | 4 | `"TRCK"` |
| 0x08–0x09 | 2 | BE16 トラック全体長 |
| 0x0A–0x0B | 2 | BE16 ファイル番号 |
| 0x0C | 1 | チャンネル番号（0–15） |
| 0x0D | 1 | インデックス数 |
| 0x0E–0x0F | 2 | BE16 ヘッダ長（通常 0x0010） |

**INDX チャンク**（通常 0x10〜）：`"INDX"` + 予約 + BE16 長 + BE16 インデックス数 N → 制御子（4 バイト×N）→ 時刻ペア（8 バイト×N）。

**SUB0 チャンク**：`"SUB0"` + 予約 + BE16 長 + BE16 サブ数 M → 制御子（4 バイト×M）→ 時刻ペア（8 バイト×M）。インデックスの制御子が `0x80000000` のとき、その時刻ペア位置に SUB0 へのオフセットが入ります。

### 制御子（control word, 4 バイト）

8 桁 16 進表記の上位 2 ニブルで判定します。

- 1 文字目（連続再生フラグ）: `1`=次インデックスへ / `2`=次サブインデックスへ / それ以外=ストップ
- 2 文字目（種別）: `9`=クイズ出題 / `5`=クイズ正答 / `3`=クイズ誤答 / それ以外=通常
- `0x80000000`=サブインデックスを持つ（時刻ペア位置に SUB0 オフセット）

例: `0x11000000`=再生後に次インデックスへ、`0x21000000`=次サブインデックスへ、`0x01000000`=再生後停止。

### 時刻コード（MSF / フレーム）

時刻ペアは `[00][分(BCD)][秒(BCD)][フレーム(BCD)]`。本実装では `フレーム = (分×60 + 秒)×75 + フレーム` の**絶対フレーム（75fps）**として扱い、セクタの MSF と TBL の時刻を**直接比較**します（リードイン補正は行いません）。

### クイズ（アンサー）

- サブインデックス **0 = 出題**、**1 以降 = 選択肢**。
- 数字ボタン K（1 始まり）は **サブインデックス番号 K** に対応し、有効なのは選択肢数（= サブ数 − 1）の範囲のみ。
- 種別フラグ `9`=出題、`5`=正答、`3`=誤答。出題・正答の再生中は ANSWER 桁に `A` を点灯、停止/一時停止/誤答再生中は点滅。選択肢再生中は選んだ番号を 12 桁目相当に表示。

### XA ADPCM デコード

ユーザーデータ 2304 バイト = **18 サウンドグループ × 128 バイト**。1 グループ = ヘッダ 16 バイト + データ 112 バイト（28 ワード×4 バイト）。モノラルでは 1 グループ 8 ブロック×28 サンプル = **224 サンプル**、1 セクタ 224×18 = **4032 サンプル**。

**ブロックヘッダ（1 バイト）**: bit5–4=フィルタ（0–3）、bit3–0=シフト。`shift = 12 − (header & 0x0F)`（範囲外は 9 にフォールバック）。

**フィルタ係数**

```
PosTable = { 0, 60, 115,  98, 122 }
NegTable = { 0,  0, -52, -55, -60 }
```

**デコード式**（4bit 符号付きニブル `nib` を符号拡張後）

```
sample = (nib << shift) + ((old * f0 + older * f1 + 32) >> 6)
```

- `f0 = PosTable[filter]`, `f1 = NegTable[filter]`
- `old`, `older` は前回・前々回の出力（セクタをまたいで状態を保持）
- 結果は −32768〜+32767 にクリップ

サンプルレートは **18,900Hz**（モノラル / 4bit）。

## 制限・未実装

- `CHAP.TBL`、CD-DA トラック（警告音声）は未対応。
- ステレオおよび 8bit XA ADPCM は未対応（モノラル 4bit・18,900Hz 固定）。
- クイズの正誤判定演出は表示中心の部分実装。
- 録音（REC/PB）は実機の代替実装で、マイク入力に依存します。
